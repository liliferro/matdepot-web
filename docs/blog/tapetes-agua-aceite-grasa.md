# ¿Qué tapete elegir para un área con agua, aceite o grasa?

Para elegir tapetes para agua, aceite o grasa, identifica la sustancia y las condiciones de contacto antes de comparar materiales. Agua, aceite mineral, grasa de cocina y productos de limpieza no son intercambiables. La compatibilidad debe confirmarse para el modelo y para la exposición prevista.

Una foto del área ayuda a entender el espacio, pero no permite identificar por sí sola una sustancia ni comprobar cómo se comportará el material. Reúne el nombre del producto utilizado y su documentación cuando esté disponible.

## Prepara un registro de exposición

| Dato | Ejemplo de información útil | Por qué cambia la consulta |
|---|---|---|
| Sustancia | Nombre comercial o identificación técnica | Evita preguntar por “químicos” sin especificar |
| Frecuencia | Derrame ocasional o contacto habitual | Describe el uso real |
| Temperatura | Condición conocida o pendiente de medir | Evita asumir comportamiento a cualquier temperatura |
| Limpieza | Producto y procedimiento empleados | El limpiador también entra en contacto con el tapete |
| Acumulación | Líquido sobre o debajo del recubrimiento | Permite revisar drenaje y retiro |

Si desconoces un dato, márcalo como pendiente. No completes una solicitud con valores estimados que podrían interpretarse como condiciones confirmadas.

## Drenaje no significa resistencia química

Los orificios o canales pueden formar parte de un diseño para manejar líquidos, pero no prueban que el material sea compatible con cualquier aceite o grasa. Tampoco indican que el agua desaparezca: hay que revisar dónde llega y cómo se limpia debajo.

## Revisa el sistema completo

Además del material, documenta el piso base, las pendientes y las coladeras existentes. Si el tapete se desplaza, se levantan bordes o se acumulan residuos, la solución puede requerir cambiar la operación, la limpieza o la instalación.

Indica si pasan equipos. Una zona húmeda que también recibe carritos reúne requisitos diferentes a un puesto fijo de trabajo. No selecciones el producto con una sola palabra como “antiderrapante” sin describir ambos usos.

## Qué debe confirmar la respuesta del proveedor

Pide que se identifique el producto exacto, las sustancias consultadas y las condiciones admitidas. Si la respuesta es general, pregunta si contempla temperatura, frecuencia y procedimiento de limpieza de tu proyecto. Si no hay información suficiente, conserva ese punto como pendiente antes de comprar.

Una prueba acordada debe tener condiciones y criterios definidos; no debe presentarse como garantía para usos que no se evaluaron. Tampoco es recomendable mezclar químicos o modificar diluciones para “probar” un tapete.
