# ¿Qué datos necesitas para cotizar tapetes o pisos técnicos?

Los datos para cotizar tapetes deben describir uso, medidas, superficie existente, cantidad y destino de entrega. Si no conoces el producto, empieza por el problema que necesitas resolver y añade fotografías. No hace falta elegir un modelo sin orientación para poder solicitar una propuesta.

Una solicitud ordenada reduce aclaraciones porque separa lo que ya está definido de lo que necesita revisión. También permite que las propuestas de distintos proveedores respondan al mismo proyecto.

## La información básica de una solicitud útil

| Dato | Qué conviene enviar | Qué evitar |
|---|---|---|
| Uso | Actividad y condiciones de cada zona | “Para uso rudo” sin explicar la operación |
| Medidas | Largo, ancho y unidad; croquis si hay varias zonas | Mezclar centímetros y metros sin identificarlos |
| Entorno | Base, líquidos, ruedas, equipos o impactos | Suponer compatibilidad por apariencia |
| Cantidad | Área medida o piezas de un modelo conocido | Presentar una estimación como pedido confirmado |
| Entrega | Ciudad, código postal y condiciones de acceso | Suponer que el flete es igual para cualquier destino |
| Alcance | Suministro, instalación u orientación requerida | Dar por incluidos trabajos que no se mencionan |

Si hay varios puestos o zonas, identifica cada uno por nombre. Para un gimnasio, separar máquinas y pesas comunica más que una sola cifra total. Para una cocina, distinguir lavado y preparación evita ocultar condiciones diferentes dentro de un mismo pedido.

## Qué fotografías ayudan realmente

Incluye una vista general que muestre el espacio y acercamientos de las condiciones relevantes: base, uniones, obstáculos, remates o producto existente. Explica qué muestra cada foto y acompáñala con medidas; una imagen no permite deducir dimensiones exactas.

Si buscas reemplazar un producto, envía también cualquier etiqueta, factura o referencia anterior. Una fotografía puede ayudar a identificar alternativas, pero no certifica que dos materiales visualmente parecidos sean iguales.

No incluyas información personal innecesaria ni documentos ajenos al proyecto. Para la primera orientación suele ser más útil una descripción clara del uso que una colección grande de archivos sin contexto.

## Cómo indicar una cantidad sin comprometer el pedido

Si solo conoces la superficie, indica que es una medida del proyecto. Si ya calculaste piezas, aclara el formato y si consideraste reserva. Las medidas útiles, cortes y presentación comercial pueden cambiar la cantidad final.

El [esponjoso con franjas amarillas](https://www.matdepotmex.com/tapetes/tapete-esponjoso-con-franjas-amarillas.html), por ejemplo, publica 90 cm de ancho y longitudes de 3, 6, 12 o 18 m. Pedir “un rollo” sin especificar presentación no define la cantidad. Para gimnasio puedes apoyarte en la [calculadora de superficie](https://www.matdepotmex.com/blog/mejor-piso-para-gimnasio.html#calculadora).

## Antes de enviar y antes de comprar

Revisa unidades, destino y fecha deseada. Distingue una fecha objetivo de una entrega confirmada. Si necesitas instalación, indícalo y describe el acceso y la disponibilidad del área; el alcance debe quedar reflejado en la respuesta.

Al recibir la cotización, verifica que coincida con la solicitud y que identifique producto, cantidad, conceptos incluidos y pendientes. No interpretes una recomendación preliminar como aprobación para un uso que no se describió.
